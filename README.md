# Aditya Mitter

London. I build software that measures things properly (an iPhone push-up counter that uses sound instead of a camera, a handwriting reader for invoices) and websites for businesses through my one-person studio, HELIOS.

## Projects

- **[Sonar Reps](https://github.com/adityamitter15/sonar-reps)**: counts push-ups on an iPhone from the echo of near-ultrasonic tones, with no camera. 2nd place at the QMUL AI x CS Hackathon, built with a team of four. The README lists what it gets wrong as well as what it gets right.
- **[Handwritten Invoice OCR](https://github.com/adityamitter15/invoice-ocr-prototype)**: reads handwritten supplier invoices with several OCR engines and sends them to a review queue where a person corrects and approves each one.
- **[DKK London](https://github.com/adityamitter15/dkk-site)**: website for Daigaku Karate Kai London, a karate club, live at [goju-karate.co.uk](https://www.goju-karate.co.uk).
- **PressPass** (private): an iOS app that verifies press-ups on-device with the front camera, plus a harness that replays recorded sessions to measure accuracy. Work in progress.
- **HELIOS** (private): my one-person web studio, and the code for its site.

## Languages and tools

Python, Swift and SwiftUI, TypeScript, JavaScript, React, Next.js, Tailwind CSS, FastAPI, NumPy and SciPy, PyTorch, Firebase Hosting.
